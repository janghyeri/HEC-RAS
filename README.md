# 힌남노 침수 다시보기 · Hinnamno Flood Replay

2022년 태풍 힌남노 때 포항 냉천 유역의 **HEC-RAS 1D–2D 외수·내수 침수해석**을 웹에서
**조건 설정 → 모델 실행 → 지도/3D 시각화 → 시나리오 비교**까지 할 수 있게 연결하고,
시민도 "어디가, 언제, 얼마나" 잠겼는지 볼 수 있게 공개하는 웹서비스.

> 경북대학교 CVLE0764 개수로 및 유사이동론 (김병현 교수님) · 2026-2학기 과제
> "바이브 코딩을 활용한 수리·수문 모델 기반 웹앱 개발 및 배포"

## 구성

| 폴더 | 내용 | 실행 위치 |
|---|---|---|
| `web/` | Next.js 웹앱 — 지도·대시보드·3D·조건 설정 | Vercel (Root Directory = `web`) |
| `worker/` | HEC-RAS 실행 워커 — 작업 조회·입력 수정·계산·결과 업로드 | HEC-RAS 6.6 설치 Windows PC |
| `pipeline/` | HEC-RAS 결과(HDF) → 웹 형식 변환 | 워커와 공유 |
| `mcp/` | (선택) AI가 자연어로 HEC-RAS를 다루는 MCP 서버 | 로컬 |
| `supabase/` | DB 테이블 정의 | Supabase |
| `docs/` | 설계 문서 (`GUIDE.md`), PRD·계획·검증 | — |

## 모형

|---|---|---|
| 외수 | NC090901 | 냉천 상류·측방 유입 + 하류 조위 |

자세한 내용은 [`docs/GUIDE.md`](docs/GUIDE.md) §4.1.

## 데이터 정책

HEC-RAS 원자료(`*.hdf`, `*.dss`, 지형 `*.tif` 등)는 이 저장소에 올리지 않는다.
워커가 Windows PC의 모형 폴더에서 직접 읽고, 웹에는 변환된 결과만 올린다.

## 진행 상황

개발 순서와 진행 현황은 로컬 작업 폴더의 `1. 과정/01_작업 진행 가이드.md`에서 관리한다.
